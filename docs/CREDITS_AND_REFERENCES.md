# Credits and References

This project was built as an independent implementation, but the theory and methodology were learned and cross-checked using the following resources.

## Academic and Course References

- Professor Scott Chiu's fixed-income course notes, Rutgers MQF, Fall 2025.

## PCA, Yield-Curve Factors, and Hedging

- [PCA Yield Curve Modelling](https://github.com/andreranza/pca-yield-curve-modelling): useful explanation of PCA applied to yield-curve modelling.
- [Fixed Income Risk, PCA, Duration, and Convexity](https://tristanweb.com/blog/fixed-income-risk-pca-duration-convexity/): practical explanation of duration, convexity, and PCA in a fixed-income risk setting.
- [PCA hedging resource](https://www.risk.net/sites/default/files/import_unmanaged/risk.net/data/Specal_Reports/pdf/interestrisk/pca.pdf): reference used for PCA-based interest-rate risk and hedging intuition.
- [PCA for Yield Curve Modelling](https://www.moodys.com/web/en/us/insights/resources/2014-29-08-pca-for-yield-curve-modelling.pdf): deeper reference on PCA methodology for yield-curve modelling.
- [NYU V-Lab Fixed Income Documentation](https://vlab.stern.nyu.edu/docs/fixedIncome): broad fixed-income resource used for review and interview preparation around the project.

## VaR Backtesting

- [MathWorks: Overview of VaR Backtesting](https://www.mathworks.com/help/risk/overview-of-var-backtesting.html): reference for VaR backtesting concepts and interpretation.

## Note

These references helped guide the theory and validation checks. Any mistakes, simplifications, or implementation choices in RatesFactor are my own.
